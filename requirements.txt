# >=0.0.57 was regression-tested against 0.0.55 across the template,
# extensions manual and user guide. Authored HTML, search content and PDF
# rendering were unchanged; Zensical's bundled assets have their expected
# new hashes. Earlier floors were checked with the same output comparisons.
zensical>=0.0.57
# A floor here and everywhere in CI: a project should receive compatible
# prodockit fixes without waiting for the template to be updated and synced.
# >=0.13.0 would be the true functional minimum (`prodockit
# sync-repo`, which replaced sync_repo_icon.py); >=0.15.2 added the
# Mermaid/TeX checks' font-ligature handling this project discovered (issue
# #128); >=0.17.2 added `prodockit pins` itself (see
# .github/workflows/docs.yml's own pin lines, and CONTRIBUTING.md), which
# manages the exact zensical/weasyprint pins and prodockit's floor below and
# in CI together, rather than by hand across several files.
#
# 0.20.1 was a genuine functional minimum for *this* template rather than
# a floor tracking the exact pin: the pipelines here pin PANDOC_VERSION
# 3.10.1, and on that pandoc every prodockit before 0.20.1 loses the
# `<pre>` around each fenced code block - the block then reflows as
# justified prose in the PDF while the build reports success
# (prodockit-extensions#207). A project generated from this template
# inherits the pandoc pin, so it inherits that floor with it.
#
# >=0.21.0 raised it again for the same reason as >=0.13.0/>=0.17.2 above:
# `prodockit source-bundle` (this template's own Source PDF, see
# CONTRIBUTING.md and the CI workflow files) does not exist before it -
# `pdf_source_bundle`, the setting this template used to set in
# zensical.toml, was removed the same release the command was added
# (prodockit-extensions#212, prodockit-template#160).
#
# >=0.26.2 raises it once more: `prodockit init-mathjax` (issue #167)
# replaces the heredoc that previously duplicated bootstrap's own MathJax
# install in CI - two copies of a config whose failure mode is being
# subtly wrong rather than broken outright (prodockit-extensions#276).
#
# >=0.49.1 carries the current canonical website and PDF stylesheet pair,
# checks both managed files alongside dependency pins, and leaves extra.css
# and print.css available for project-specific overrides.
# >=0.54.0 adds the read-only `pdk diag` environment and project gate used by
# both publishing workflows instead of a template-owned test suite.
prodockit>=0.54.0
